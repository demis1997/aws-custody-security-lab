# Security reporting and scope

This is an experimental infrastructure and policy research lab, not a production custody service. Do not place real assets, seed material or production credentials in it. The tests use synthetic keys and logical signing authority; none is an audited MPC implementation.

For sensitive reports, use GitHub private vulnerability reporting when enabled or arrange a private channel with the repository owner before sharing enabling details. Do not put secrets or live attack material in a public issue. Non-sensitive reproducibility/documentation issues can be public.

A useful report includes source revision, attacker prerequisites, affected boundary, reproducible synthetic test and the exact executed scope. Distinguish unsafe configuration assumptions from a newly discovered cryptographic vulnerability. No vulnerability in Coinbase cb-mpc or a production custodian is claimed here.
